🔐 Account architecture

BUCKTRACK uses IndexedDB for local accounts and hunt records. Passwords are stored as SHA-256 hashes rather than plain text. Static GitHub Pages cannot provide true internet-wide authentication or shared cloud chat without a backend.
BUCKTRACK is a hunting planning and journaling tool. Follow current Nova Scotia hunting laws, landowner permissions, legal shooting hours, firearm/bow regulations, identification requirements and safe backstop practices. Weather and movement scores are estimates, not guarantees.
