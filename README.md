## Precision notes

- GPS: `enableHighAccuracy`, accuracy ring when available
- SOS bearings: WGS84 Vincenty
- Land 3D: MapLibre + AWS Terrarium DEM + Esri imagery
- Weather: Open-Meteo (no key)
